# Control de nómina y gastos

Aplicación React + Vite para registrar:

- Nómina mensual.
- Gastos fijos mensuales recurrentes (hipoteca, comunidad, luz, agua, etc.).
- Gastos variables diarios.
- Gastos puntuales o extraordinarios.
- Visualización por mes, año completo o rango de meses.

## Ejecutar

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

Los datos se guardan en `localStorage` del navegador.
